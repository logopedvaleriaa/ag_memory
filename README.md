# Открой волшебство

Артикуляционная игра мемори. Локальная браузерная игра с тремя акварельными сюжетами и 16 упражнениями.

[Играть в браузере](https://logopedvaleriaa.github.io/ag_memory/) · [Репозиторий на GitHub](https://github.com/logopedvaleriaa/ag_memory)

## Локальный запуск

Нужен Node.js. Устанавливать зависимости не требуется.

```sh
cd forest-memory
npm start
```

Откройте http://localhost:3000. Для остановки нажмите Ctrl+C. Другой порт: `PORT=3001 npm start`.

Можно открыть `dist/index.html` напрямую. Внешние Google Fonts необязательны: если сеть недоступна, используются системные шрифты.

## Как играть

1. Выберите сюжет. При каждом открытии игры сначала показывается выбор, без сюжета по умолчанию.
2. Выберите от 2 до 16 упражнений и длительность таймера.
3. Открывайте по две карточки. Найдите пару и выполните упражнение — таймер запустится автоматически.
4. Когда отсчёт закончится, окно упражнения закроется автоматически. Пара исчезнет, а награда отправится в выбранный сюжет. Кнопка «Выполнили» завершает упражнение раньше.
5. После всех упражнений запустится финальная анимация.

Выбор упражнений, длительность таймера и избранное сохраняются в браузере. Сюжет можно сменить до начала занятия и во время игры: расположение карточек и прогресс сохраняются. Для смены во время игры завершите текущее упражнение и дождитесь доставки награды.

Кнопка «Выбрать все» выбирает все 16 упражнений, «Сбросить все» очищает выбор.

Все экраны помещаются в окно без прокрутки. Размер и раскладка карточек автоматически подстраиваются под окно, включая набор из 16 упражнений (32 карточки). Изменение размера окна не сбрасывает игру.

## Сюжеты

- **Звёздная почта** — найденная пара становится письмом с желанием. Письмо летит в волшебный почтовый ящик на облаке и зажигает звезду. В финале созвездие освещает сказочный городок.
- **Мастерская чудес** — огоньки заряжают машину. В финале появляются бумажные птицы.
- **Море находок** — жемчужины попадают в сундук. В финале появляются рыбки.

При системной настройке «уменьшение движения» анимации отключаются, награды и прогресс сохраняются.

## Файлы

- `dist/index.html` — оболочка приложения.
- `dist/style.css` — темы, анимации и адаптация к экранам.
- `dist/app.js` — сюжеты, упражнения и игровая логика.
- `dist/exercises-mail.png`, `dist/exercises-workshop.png`, `dist/exercises-sea.png` — 16 упражнений в трёх палитрах: голубой с золотом, шалфейной с медью и бирюзовой с коралловым. Эти иллюстрации используются в выборе упражнений, на поле и в окне таймера.
- `dist/exercises-transparent.png` — исходный прозрачный набор, сохранён отдельно.
- `dist/workshop-transparent.png`, `dist/sea-refined.png` — иллюстрации мастерской и моря без фона. Сундук приведён к общему акварельному стилю; предыдущая версия `sea-transparent.png` сохранена отдельно.
- `dist/card-backs.png` — рубашки трёх сюжетов: посылка, ящичек и ракушка.
- Исходные изображения без суффикса `-transparent` сохранены отдельно.
- `server.cjs` — локальный сервер без зависимостей.
- `art-prompts.md` — исходные промпты иллюстраций сюжетов.
- `art-prompts-transparent.md` — промпты прозрачных иллюстраций и рубашек.
- `dist/mail-magic.png`, `dist/wishes-sky.png` — волшебный почтовый ящик и звёздный городок.
- `art-prompts-magic.md` — промпты новых иллюстраций почты.
- `art-prompts-themes.md` — промпты трёх тематических наборов упражнений.

Проверка синтаксиса: `npm run check`.

Полный отчёт о проверке — в [QA.md](QA.md). Повторяемые браузерные проверки сохранены в `tests/browser-review.cjs`. Для них отдельно нужен Playwright; обычный запуск игры по-прежнему не требует зависимостей.

При работающем локальном сервере:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

Результат записывается в `test-results/browser-review.json`. Для другого адреса сервера используйте `GAME_URL=http://localhost:3001 npm run test:browser`.

## Отображение иллюстраций

Для всех 48 упражнений и трёх рубашек заданы индивидуальные границы в `EXERCISE_ARTWORK` и `COVER_ARTWORK` в `dist/app.js`. Вложенные SVG-области показывают только нужный предмет и оставляют прозрачный отступ; соседние картинки с общего листа не видны. Один способ отображения используется в выборе упражнений, на поле и в окне таймера. При замене PNG-листов нужно обновить эти координаты.

## Разработка и публикация

Для GitHub загружайте содержимое этой папки в корень репозитория, включая `.github/workflows/pages.yml`. Служебная папка `.openai` и история прежнего хостинга для новой публикации не нужны.

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. После отправки изменений в ветку `main` workflow `Publish game to GitHub Pages` проверит JavaScript и опубликует содержимое `dist`. Первый запуск также можно выполнить вручную на вкладке **Actions**.

Готовая ссылка появится в **Settings → Pages** и в результате workflow. Сборка и установка зависимостей для публикации не требуются. Локальный сервер `server.cjs` на GitHub Pages не запускается.
